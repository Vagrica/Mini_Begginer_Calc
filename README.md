# FEATURES: 

The calculator allows you to calculate continously with the previous answer.
We have 4 simple operators to make calculations with!
Operator 1: +
Operator 2: -
Operator 3: *
Operator 4: /

Also the program protects you from dividing by zero, so don't worry about that ;3
